# Pool of Radiance

This is an attempt to translate Pool of Radiance into a runnable web app, with the intention of possibly modifying it in ways I find personally enjoyable. Just a little hobby project, not something I necessarily intend to share.

## Translation Plan and Status

### First pass

Keeping as close to line-by-line original as possible - a lot lost in translation that will just hang around doing nothing. Deleting pointers though.

includes: 13/28
src: 3/56

### Second pass

Removing anything left over that is doing nothing.

### Third pass

More logical translation; doing things the way web apps typically do them, instead of Turbo Pascal's lower-level conventions.

### Fourth pass

Any remaining cleanup and optimization. Maybe deleting old pas files.
